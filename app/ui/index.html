Stuck-at fault diagnosis · VLSI

Find the broken wire inside a chip you cannot open.

A manufactured chip can hold one internal wire permanently at 0 or 1. You cannot see inside it — only what comes out of the pins. Faultiva reads a recording of how the circuit responded to a fixed set of test patterns and reports whether a fault exists, what type it is, and which gate it sits on.

How it works

Three stages, deliberately using different evidence. The first two carry no learned weights at all — an exact comparison and a hash lookup are always right, where a model only might be.

010 parameters

Detection

Observed responses are compared byte-for-byte against the fault-free reference. Any difference means a fault. No threshold, so a clean circuit cannot raise a false alarm.

020 parameters

Localization

All four response channels across every vector hash into one behaviour signature, looked up in a catalogue built by injecting every stuck-at fault. A lookup, not an estimate.

0393,185 parameters

Verification

A neural network independently scores the candidate using circuit structure only — it never sees the responses. Agreement between disjoint evidence is real corroboration.

What the capture file contains

One line per test vector, four measured channels. A fault does not always corrupt the output bytes — it can hang the circuit, break the handshake, or simply finish late. Recording one channel would miss those.

What it does not do

Each of these was measured rather than assumed. They are stated plainly because a tool that hides its failure modes is harder to trust than one that names them.

Some faults cannot be separated

99.8% of HMAC faults have a structural twin producing identical output on every vector. No response-based method can tell them apart, so the candidate set is reported rather than a guess.

Simulation, not silicon

Validated in Verilator against real third-party RTL. No physical chip has been tested.

Single stuck-at faults only

Multiple simultaneous, bridging, delay and transient faults are out of scope and return UNKNOWN_SIGNATURE rather than a confident wrong answer.

Four circuits are catalogued

Localization needs a per-circuit injection campaign. Detection works on anything with a fault-free reference.

Catalogue growth reduces resolution

Same circuit, same faults, catalogue grown four times larger — exact-site identification fell by 19×. Measured and published rather than hidden.

Two circuits were not scorable

The acquired ibex_cpu source was missing seven dependencies. Substitute RTL was refused, because characterizing a stub would have measured the stub.
